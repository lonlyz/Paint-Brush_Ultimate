### Como usar?
  Para usar apenas é necessário rodar o arquivo "main.py" que está no diretorio "src/Paint-Brush_Ultimate/".
---
  O programa irá iniciar com o quadro totalmente branco e com a função de mão livre(ou rabisco) ativada como padrão. O usuario pode escolher entre várias figuras presentes na interface do programa e trocar a cor deles com a opção de selecionar cor.
